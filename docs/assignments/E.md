# E 任务书

## 角色

检测、故障和维修记录模块负责人。

## 负责范围

- 设计检测与维修模块的表和分 ER 图。
- 编写字段说明、主外键和维修规则。
- 实现故障分类、检测记录和维修记录的 Controller、Service、Mapper。
- 实现待检测列表、检测登记和维修登记接口。
- 实现检测与维修页面。
- 编写至少一条按故障分类查询维修记录的 SQL。
- 完成本模块接口测试和页面测试。

## 不负责

- 不实现客户申请和保修查询。
- 不自行修改 RMA 状态规则；和 B 约定调用方式。
- 不直接向上游 `main` 推送代码。

## 交付

- 检测与维修模块 ER 图
- 字段和业务规则说明
- 检测与维修后端代码
- 检测与维修页面
- 手写 SQL、测试结果和页面截图
- 关联 Issue 的 PR

## 验收

- 维修人员只能处理处于正确状态的 RMA。
- 检测与维修记录能关联 RMA 和产品。
- 已结案 RMA 不能新增检测或维修记录。
- 页面数据来自 MySQL，不使用前端写死数据。
- 能在答辩中解释故障、检测和维修记录的关系。

## 依赖与求助

- A 检查模块表设计和跨模块关系。
- B 提供 RMA 状态接口并定期审查本模块。
- 先在 Issue 说明问题和日志，再 @B 处理后端疑问。
