# B 任务书

## 角色

公共后端、权限、RMA 状态流程和后端代码审查。

## 负责范围

- 准备 Spring Boot 公共项目结构。
- 配置 MySQL、MyBatis-Plus 和统一接口响应。
- 实现登录以及客服、维修人员、管理员三个角色。
- 实现 RMA 状态推进、换新和结案。
- 提供 Controller、Service、Mapper 的参考模块。
- 审查跨模块接口和异常处理。
- 定期检查 E 的检测维修模块。

## 不负责

- 不代替 C、D、E 完成各自后端。
- 不自行修改其他模块的数据表；先在 Issue 中提出需求。
- 不执行上游仓库的最终合并。

## 交付

- 公共后端结构
- 统一接口响应与异常处理
- 登录和三个角色的权限控制
- RMA 状态、换新与结案功能
- RMA 状态说明
- 对 C、D、E 的后端审查记录

## 验收

- 三个角色的操作范围不同。
- 非法 RMA 状态跳转被拒绝并返回原因。
- 换新记录能关联原 SN 与新 SN。
- 已结案 RMA 不能继续新增维修数据。
- C、D、E 可以参照公共模块独立开发。

## 依赖

- A 提供数据库规范、核心表关系和页面规范。
- D 提供已受理的售后申请。
- E 提供检测与维修结果。
