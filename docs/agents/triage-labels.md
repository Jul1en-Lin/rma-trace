# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to the labels used in this repository.

| Label in mattpocock/skills | Label in this repository | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires work or a decision from a person |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a triage role, use the corresponding repository label from this table.
